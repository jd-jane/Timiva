Timiva V1 第一個核心工具。

## 用途

建立重要事件的倒數，讓使用者在手機上快速看見「距離那一天還有多久」。適合新年、節日、紀念日與自訂目標日期。

## 主要功能

```text
自訂事件名稱與目標日期
Quick templates（含中文：2027 新年、2026 聖誕節、2027 情人節）
Theme 主題切換
Share 分享
Edit sheet / Theme sheet
EN / ZH 雙語
FAQ / JSON-LD
Related Tools
Mobile portrait / landscape / Desktop 已驗收
```
