# Timiva

手機優先、低維護的時間與生活節奏工具網站。

## 技術堆疊

```text
Astro
Tailwind CSS
Cloudflare Pages
English / 繁體中文
```

## 本機啟動

```bash
npm install
npm run dev
```

## 主要語系與路由

```text
/en/…   英文
/zh/…   繁體中文
```

## 文件入口

正式文件請從 [`docs/README.md`](docs/README.md) 開始。

```text
AGENTS.md              Cursor 任務入口
docs/README.md         文件索引、閱讀順序、tracked / local-only 規則
docs/workflow/         Owner 工作流（P / S / M / L）
docs/project/          目前狀態與決策紀錄
local-docs/            本機工作文件（不進 Git，需自行備份）
```
